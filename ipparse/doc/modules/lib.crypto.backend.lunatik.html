Module lib.crypto.backend.lunatik

Lunatik crypto backend for ipparse (no FFI).

Implements the ipparse crypto interface using Lunatik's kernel crypto Lua API. Requires a Lunatik runtime with: - require("crypto").aead (for AES-128-GCM) - require("crypto").skcipher (for AES-128-ECB, ephemeral allocation)

Implements: aes128gcmencrypt(key, nonce, plaintext, aad) → ciphertextwithtag aes128gcmdecrypt(key, nonce, ciphertextwithtag, aad) → plaintext | nil, err aes128ecbblock(key, block) → encryptedblock (with fallback)

Note: ECB uses skcipher with ephemeral allocation to avoid persistent memory pressure. If ECB fails, returns nil so caller can skip this packet and retry later.

Functions

is_ebadmsg (err)
Checks whether an error value denotes EBADMSG. Compares the whole string so digits embedded in other errnos (e.g. -174) are not matched. Lua's error() prepends "chunk:line: "; Lunatik's lunatikthrow() calls luaerror() directly, without such a prefix.

Parameters:

  • err string Error value

Returns:

    boolean true if the error is EBADMSG
ebadmsg_error (err)
Normalizes an EBADMSG from either Lunatik convention to the public error.

Parameters:

  • err string Error value (name, "-NAME" or signed decimal)

Returns:

    string or nil Authentication error message, or nil if not EBADMSG
aes_128_gcm_encrypt (key, nonce, plaintext, aad)
Encrypts with AES-128-GCM.

Parameters:

  • key string 16-byte key
  • nonce string 12-byte nonce
  • plaintext string Data to encrypt
  • aad string Additional authenticated data (optional)

Returns:

    string ciphertext || tag (16 bytes appended to ciphertext)
aes_128_gcm_decrypt (key, nonce, ciphertext_with_tag, aad)
Decrypts with AES-128-GCM.

Parameters:

  • key string 16-byte key
  • nonce string 12-byte nonce
  • ciphertext_with_tag string Ciphertext with 16-byte tag appended
  • aad string Additional authenticated data (optional)

Returns:

  1. string plaintext on success, or nil on authentication failure
  2. string error message on failure
ecb_encrypt (key, block)
Encrypts single AES-128-ECB block. Uses a cached skcipher transform to avoid frequent allocations under load. Returns nil on failure so caller can defer processing and retry later.

Parameters:

  • key string 16-byte key
  • block string 16-byte plaintext block

Returns:

    string 16-byte ciphertext block, or nil if ECB unavailable
