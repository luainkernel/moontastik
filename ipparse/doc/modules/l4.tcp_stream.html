Module l4.tcp_stream

Generic TCP stream defragmenter.

Accumulates TCP payloads by session key; clears on FIN/RST; purges by age. Memory is bounded: per-session buffers are capped (max_buf) and so is the number of tracked sessions (max_sessions, oldest dropped first), so a flood of never-completing streams cannot grow state without limit.

new ([check_complete[, opts]])
Creates a new TCP stream defragmenter.

Parameters:

  • check_complete function Predicate (buf) -> bool. Default: always true (each segment with payload is immediately complete). When provided, feed returns nil until the predicate passes, then auto-clears the session. (optional)
  • opts table Options: max_buf (bytes per session, default 1 MiB), max_sessions (default 1024), clock (zero-arg function returning an integer instant in fixed units) and clock_hz (units per second, default 1 when clock is given; clock_hz without clock is an error). (optional)

Returns:

    table State with :feed, :clear, :reset and :purge methods.

Raises:

Error at creation when no clock is available and none is provided.
feed (key, payload, flags, init_seq)
Feed a TCP segment into the stream.

Parameters:

  • key string 
      Session key (e.g. "src|sport|dst|dport").
  • payload string TCP payload bytes (may be "").
  • flags number 
    Raw TCP flags byte.
  • init_seq number Sequence number of this segment.

Returns:

  1. string or nil Complete buffer (nil on FIN/RST, empty payload, or incomplete).
  2. number or nil init_seq of the first segment in this session.
  3. boolean or nil true if this was the first segment for this session.
