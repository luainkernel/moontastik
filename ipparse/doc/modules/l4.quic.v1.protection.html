Module l4.quic.v1.protection

QUIC v1 header and packet protection (RFC 9001).

Backend-agnostic: all cryptographic operations are delegated to a crypto backend table passed as the last argument (or returned by require "ipparse.lib.crypto.backend.ffi_openssl"). The backend must expose: aes_128_ecb_block(key, block) → 16 bytes aes_128_gcm_encrypt(key, nonce, plaintext, aad) → ciphertextwithtag aes_128_gcm_decrypt(key, nonce, ciphertext_with_tag, aad) → plaintext | nil, err

### Header protection (RFC 9001 §5.4) mask = AES-ECB(hpkey, sample) -- sample = 16 bytes from encrypted payload Long header: firstbyte ^= mask[0] & 0x0F ; pnbytes ^= mask[1..pnlen] Short header: firstbyte ^= mask[0] & 0x1F ; pnbytes ^= mask[1..pn_len]

### Packet number nonce (RFC 9001 §5.3) nonce = iv XOR (pn padded to 12 bytes, big-endian)

sample_from_packet (pkt, enc_off)
Extracts the 16-byte sample for header protection from encrypted payload. RFC 9001 §5.4.2: sample starts at offset 4 past the start of the encrypted payload.

Parameters:

  • pkt string 
    full packet bytes (binary string)
  • enc_off number 1-based offset where encrypted payload starts (after pn field)

Returns:

    string 16-byte sample
recover_packet_number (truncated, expected, pn_len)
Recovers the full packet number from a truncated one (RFC 9000 §A.3).

Parameters:

  • truncated number the pn_len-byte truncated packet number
  • expected number the expected next packet number (largest acknowledged + 1)
  • pn_len number 
     number of bytes used in the wire encoding

Returns:

    number full packet number
remove_header_protection (pkt, pn_off, hp_key, long, expected_pn, crypto)
Removes header protection from a raw QUIC Initial (long-header) packet.

Returns an immutable view: the function returns modified bytes, not a new string. Caller should reconstruct the header string only if needed.

Parameters:

  • pkt string 
          raw QUIC packet bytes (binary string, 1-based)
  • pn_off number 
       1-based offset of the (protected) packet number field
                          in the packet (computed during header parsing)
  • hp_key string 
       16-byte header protection key
  • long boolean 
         true for long header, false for short
  • expected_pn number expected next packet number (for full PN recovery)
  • crypto table 
       backend table (must have <code>aes\_128\_ecb\_block</code>)

Returns:

  1. table hdr_bytes modified byte array of the entire packet
  2. number pn recovered full packet number
  3. number pn_len packet number length in bytes (1..4)
decrypt_payload (pkt, payload_off, key, iv, pn, aad, crypto)
Decrypts a QUIC packet payload (AEAD, RFC 9001 §5.3).

Parameters:

  • pkt string 
          raw QUIC packet bytes
  • payload_off number 1-based offset of the encrypted payload (after pn field)
  • key string 
          16-byte packet protection key
  • iv string 
           12-byte packet protection IV
  • pn number 
           full recovered packet number (used to build nonce)
  • aad string 
          additional authenticated data (unprotected header bytes)
  • crypto table 
       backend table (must have <code>aes\_128\_gcm\_decrypt</code>)

Returns:

  1. string decrypted plaintext (frames)
  2. nil, string on authentication failure
