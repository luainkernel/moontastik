Module lib.hkdf

HKDF-Extract step.

Functions

hkdf_expand_bin (prk[, info=""], len)
HKDF-Expand step, binary output. Expands the pseudorandom key (PRK) to produce output keying material.

Parameters:

  • prk string Pseudorandom key from HKDF-Extract.
  • info string Context and application specific information. (default "")
  • len number Length of output keying material in bytes.

Returns:

    string Output keying material (OKM) as binary string.
hkdf_expand (prk[, info=""], len)
HKDF-Expand step. Expands the pseudorandom key (PRK) to produce output keying material.

Parameters:

  • prk string Pseudorandom key from HKDF-Extract.
  • info string Context and application specific information. (default "")
  • len number Length of output keying material in bytes.

Returns:

    string Output keying material (OKM) as hex string.
hkdf (salt, ikm, info, len)
Complete HKDF operation (Extract + Expand). Derives output keying material from input keying material using HKDF.

Parameters:

  • salt string Salt value (empty string becomes 64 zero bytes).
  • ikm string Input keying material.
  • info string Context and application specific information.
  • len number Length of output keying material in bytes.

Returns:

    string Output keying material (OKM) as hex string.
